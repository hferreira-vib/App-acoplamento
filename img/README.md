# Imagens ilustrativas das categorias de acoplamento

Coloque aqui as fotos das categorias. A aplicação (`app.py`) procura os ficheiros
pelos nomes exatos abaixo e mostra-os na secção **3. Selecao do Acoplamento**.
Se um ficheiro não existir, a app mostra uma dica amigável no lugar (não quebra).

Formato recomendado: JPG, proporção aproximadamente quadrada/paisagem, ~500 px de largura
(é exibida a 250 px de largura).
